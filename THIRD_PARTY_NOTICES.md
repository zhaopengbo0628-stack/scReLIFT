# Third-party resources

The MIT license covers original scReLIFT code and packaging additions. It does not relicense datasets, genome annotations, external executables, pretrained comparator models or upstream software.

Historical experiment adapters/configurations reference scButterfly, scMomer, ECLARE-S (historical source ID ECLARE), MultiVI/scvi-tools, MultiGrate, Cobolt, Palette and other comparator environments. Their full upstream repositories are not installed or redistributed as dependencies of the scReLIFT package. Obtain each implementation from its official release and retain its license/citation. Small historical configuration snippets are preserved for evidence; review upstream terms before publishing those snippets if required.

Python runtime dependencies (PyTorch, NumPy, SciPy, scikit-learn and threadpoolctl) retain their upstream licenses. Optional analysis tools, R/fgsea, FIMO/MEME, ENCODE SCREEN, GENCODE, motif databases and pathway databases retain their own terms. Do not infer a data redistribution grant from the code license.
